# Weather and Moon Data Parser

A Python program that pulls **weather and moon data from the internet** and converts the information into a structured HTML table.

## Purpose

This project demonstrates the process of converting **unstructured web data into a structured dataset**.

### Pipeline

`Internet Data → Unstructured HTML/Text → Parsing → Python Dictionary → Structured HTML Table`

## Features

- Retrieves weather data from the internet
- Retrieves moon data from the internet
- Parses unstructured HTML/text
- Converts extracted information into Python dictionaries
- Generates a stylized HTML table from the structured data

## Technologies

- Python
- Playwright
- BeautifulSoup
- Regular Expressions (Regex)
- HTML/CSS

## Summary

The primary goal of this project is to demonstrate how unstructured information gathered from the web can be cleaned, parsed, and transformed into a structured dataset that is easier to read and process.
